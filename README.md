# laddertp

SF has some ladders around the water that don't work. I made this mod so it 
works similarly to the markers you use to get on top of the tall pointy 
tower(s). I don't think all of them are useful to 'climb', but at least you 
can use them if you fall off and there's no boat nearby

Took inspiration from juniordjjr's ladders mod, except theirs make the 
player do an animation and _actually_ use the ladders to climb, mine just 
does a fade and the player is at top of the ladders

Usage: simply stay pretty close to the bottom of the ladders for like a second
