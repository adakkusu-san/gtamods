set current time

I couldn't find a better one (or I didn't look for long enough), so I decided 
to make my own

INI file should be self-explanatory

```
[msztime]
hour = 6
minute = 30
freeze = 1
```

if you set to "freeze" the time in the INI file, you can then press `;` to 
"unfreeze" the time

I may later add to set the weather too, and make this into a menu instead
