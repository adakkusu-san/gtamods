set current time

I couldn't find a better one (or I didn't look for long enough), so I decided 
to make my own

INI file should be self-explanatory

```
[msztime]
hour = 6
minute = 30
freeze = 0xba
```

press `;` to "unfreeze" the time. you can change the key in the INI file

I'll try to make it so you can easily change the time in-game
